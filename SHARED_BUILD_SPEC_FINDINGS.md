# Shared build specification findings

Source: https://manus.im/share/file/031a5baf-bddf-45a0-ae45-cec0b966f646

The shared file is `manix_xmd_glassmorphism_presentation_script.md`, a MANI XMD Glassmorphism Design System for a premium glass command center layered on top of the real WhatsApp automation platform.

The central requirement is to use glassmorphism as a hierarchy system rather than decoration. The product must remain fast, readable, accessible, honest about backend states, and fully functional for pairing, session management, bot controls, commands, documentation, and support.

The visual model has five layers: a dark navy/graphite base environment; subtle aurora, grid, or network atmosphere; glass surfaces that group related content; clear product content; and feedback for toast, progress, success, or error states.

Glass levels are specified as follows: Soft glass at approximately 30–45% opacity for decorative/background areas where critical text must not be placed; Standard glass at approximately 50–65% for cards, navigation, forms, and command panels; and Strong glass at approximately 75–90% for dialogs, pairing codes, QR panels, and critical content where readability takes priority.

The visible specification emphasizes a premium command-center direction, layered depth, strong hierarchy, careful contrast, restrained blur, real-state feedback, and responsive/accessibility-conscious implementation. The remaining shared document should be read in full if additional slides contain component-specific requirements.
